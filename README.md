Event Management Website

A modern, responsive, and interactive Event Management Website developed to provide users with a seamless platform to explore upcoming events, view event details, and register for their preferred events.

The website focuses on delivering an engaging user experience through an attractive interface, intuitive navigation, responsive layouts, and interactive JavaScript functionality.

Project Overview

The Event Management Website allows users to discover different events, explore event information, search for specific events, and complete registration through a validated registration form.

The project demonstrates the practical application of front-end web development technologies, including HTML, CSS, and JavaScript.

Key Features

- Modern Homepage: Attractive hero section introducing the event management platform.
- Upcoming Events: Displays upcoming and featured events in visually appealing cards.
- Event Details: Provides relevant information about individual events, including name, date, venue, image, and description.
- Event Search: Allows users to search for specific events.
- Category Filtering: Enables users to filter events based on different categories.
- Event Registration: Provides a registration form for users to register for their preferred events.
- Form Validation: JavaScript-based validation ensures that users provide valid registration details.
- Confirmation Message: Displays a success message after successful registration.
- Responsive Design: Optimized for mobile phones, tablets, and desktop screens.
- Interactive UI: Smooth transitions, intuitive navigation, and engaging interface elements.

Technologies Used

HTML5 - Website structure and content
CSS3 - Styling, layouts, animations, and responsiveness 
JavaScript - Interactivity, event filtering, search, and form validation

Getting Started

Follow these steps to run the project locally.

1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

2. Navigate to the Project Directory

```bash
cd Event-Management-Website
```
3. Run the Website

Open the `index.html` file in your preferred web browser.

Alternatively, use the Live Server extension in Visual Studio Code for a better development experience.

Registration Form

The registration form collects the following information:

- Participant Name
- Email Address
- Phone Number
- Selected Event

JavaScript validation is implemented to ensure that the submitted information meets the required input conditions.

After successful validation, users receive a registration confirmation message.
